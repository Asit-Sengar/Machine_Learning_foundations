# Naive Bayes

This folder contains basic calculations and practice work for understanding the Naive Bayes algorithm.

Naive Bayes is a simple probability-based machine learning method that uses Bayes' Theorem to classify data. It assumes that features are independent of each other.

## Formula

```text
P(A | B) = P(B | A) * P(A) / P(B)
```

Where:

- `P(A | B)` is the probability of class `A` given evidence `B`
- `P(B | A)` is the probability of evidence `B` given class `A`
- `P(A)` is the prior probability of class `A`
- `P(B)` is the probability of evidence `B`

- Step-by-step manual calculations
